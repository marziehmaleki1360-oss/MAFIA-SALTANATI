مافیای سلطنتی – پروژه اندروید آفلاین – نسخه 1.2.0
====================================================

این بسته، سورس کامل پروژه اندروید و گردش‌کار GitHub Actions برای ساخت APK آزمایشی (Debug) است.
APK از پیش ساخته‌شده داخل ZIP نیست؛ پس از اجرای موفق گردش‌کار، فایل APK در بخش Artifacts گیت‌هاب قابل دریافت خواهد بود.

امکانات موجود در نسخه بازی:
- اجرای محلی و آفلاین؛ بدون نیاز به سرور
- رابط فارسی و راست‌چین
- بازی ۸ و ۱۲ نفره با بازیکنان رایانه‌ای
- نقش‌های مافیا، دکتر، کارآگاه و شهروند
- چرخه شب و روز، عملیات نقش‌ها، بحث و رأی‌گیری
- ذخیره محلی پروفایل، آمار و بازی نیمه‌تمام با حافظه محلی برنامه
- فروشگاه نمونه و تنظیمات بازی
- برنامه اندروید مبتنی بر WebView و سازگار با Android 6.0 به بالا (minSdk 23)

ساخت APK فقط با گوشی:
1) فایل ZIP را از حالت فشرده خارج کنید.
2) پوشه mafia_saltanati_v1_2 را در یک مخزن GitHub جدید بارگذاری کنید؛ فایل‌ها و پوشه‌های داخل آن باید در ریشه مخزن قرار بگیرند. پوشه .github را هم حتماً بارگذاری کنید.
3) در مخزن GitHub وارد زبانه Actions شوید و گردش‌کار Build Mafia Saltanati APK را انتخاب کنید.
4) روی Run workflow بزنید و منتظر بمانید تا اجرا با علامت سبز تمام شود.
5) وارد صفحه همان اجرای موفق شوید. پایین صفحه، در قسمت Artifacts، فایل mafia-saltanati-debug-apk را دانلود کنید.
6) ZIP مربوط به Artifact را در گوشی باز کنید و app-debug.apk را نصب کنید. ممکن است اندروید برای نصب از منبع انتخاب‌شده اجازه بخواهد.

نکات مهم:
- گردش‌کار از Java 17، Gradle 8.9، Android Gradle Plugin 8.7.3 و Android SDK 35 استفاده می‌کند.
- این خروجی Debug برای نصب و آزمایش شخصی است، نه انتشار رسمی در فروشگاه‌ها.
- این پروژه بازی آفلاین تک‌دستگاهی با بازیکنان رایانه‌ای است؛ چندنفره اینترنتی، پیامک/ورود واقعی، همگام‌سازی ابری و پرداخت واقعی ندارد.
- سکه‌ها و الماس‌های فروشگاه نمونه، پول واقعی یا اعتبار قابل خرید نیستند.
- پیشرفت بازی و پروفایل روی همان دستگاه ذخیره می‌شوند. پاک‌کردن داده‌های برنامه یا حذف برنامه ممکن است اطلاعات محلی را از بین ببرد.
- پروژه در این محیط با Android SDK ساخته نشده است؛ موفقیت نهایی ساخت باید در GitHub Actions تأیید شود.
